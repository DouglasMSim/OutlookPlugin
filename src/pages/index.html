Reply All with Attachments: pilot install

An Outlook button that opens a normal Reply All with the message's files already attached.

Download manifest.xml

Install in your mailbox

  1. Download manifest.xml with the button above.
  2. Open aka.ms/olksideload and sign in with your Microsoft 365 work mailbox. It opens Outlook on the web with the add-ins window.
  3. Choose My add-ins. Under Custom Addins, choose Add a custom add-in → Add from File.
  4. Select the downloaded file and choose Install.
  5. Open a message that has attachments and look for Reply All with Attachments.
    • Classic Outlook for Windows: the Home ribbon, or the message's Message tab when it's open in its own window.
    • New Outlook for Windows and Outlook on the web: the Apps button, or the … menu on the message.

The install belongs to your mailbox, so it also appears in classic and new Outlook for Windows after they restart. It can take a few minutes to show up.

If “Add a custom add-in” is missing

Your organization blocks personal add-ins. Ask your Microsoft 365 admin to deploy this manifest to a pilot group from the Microsoft 365 admin center (Settings → Integrated apps → Upload custom apps).

Remove it

Open aka.ms/olksideload, find the add-in under Custom Addins, choose … → Remove.

Privacy

Messages and files are handled entirely inside Outlook. This site only serves the add-in's code; nothing about your mail is sent here.
